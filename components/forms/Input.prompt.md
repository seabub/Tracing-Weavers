Underline-only text field with a letterspaced caps label above; red underline on focus.
```jsx
<Input label="Organization" placeholder="Foundation, fund or company" />
<Input label="Email or WhatsApp" error="Required" />
<Input label="Message" multiline rows={3} />
```
Props: label, hint, error (replaces hint, turns red), multiline/rows, inverse for ink grounds, disabled.
