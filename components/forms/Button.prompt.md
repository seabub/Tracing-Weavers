Square, letterspaced-caps button; primary is red fill, secondary is ink outline, ghost is red text. Use one primary per view ("Join the 3-Year Journey", "Become an Impact Partner").
```jsx
<Button>Join the 3-year journey</Button>
<Button variant="secondary" size="sm">Request a meeting</Button>
<Button inverse>On dark slide</Button>
```
Props: variant primary|secondary|ghost · size sm|md|lg · inverse (salmon on ink) · disabled · fullWidth.
