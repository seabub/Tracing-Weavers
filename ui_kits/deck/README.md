# Fundraising deck kit
Recreation of the seven slide archetypes in "Beyond Tenun Fundraising Deck v3" (Canva, 1920×1080), authored at 1280×720.
- slides.jsx — TitleSlide, StatementSlide, ProblemSlide, StepsSlide, StatsSlide, TableSlide, ClosingSlide, SlideFrame
- index.html — click-through deck (arrow keys / click)
- One HTML per slide type for the Design System tab.
Grounds alternate between ink (#201E1D) and paper (#F3F2F2). Every slide opens with a red/salmon eyebrow and closes with a hairline footer line.
